# Requirements are read-only input

`docs/project_context.md`, `docs/US-INIT-1.md` and `docs/US-STUD-1.md` are the course owner's input, in Ukrainian. Never edit them (a hook blocks it).

- If a requirement is missing, contradictory or ambiguous, write it down in the "Open questions" section of `docs/architecture/overview.md` or in `docs/analysis/requirements-digest.md`, and say so in your answer.
- Cite the story and scenario (`US-06 sc.3`) when a rule comes from here; user-facing strings are English translations of the acceptance-criteria texts.
